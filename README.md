# HCI-LAB
# JCI Website

## Deskripsi

JCI Website merupakan proyek **Human-Computer Interaction (HCI)** berupa pengembangan antarmuka website untuk mendukung penyampaian informasi dan interaksi pengguna dengan JCI. Proyek ini berfokus pada perancangan interface yang informatif, terstruktur, dan mudah digunakan dengan menerapkan prinsip-prinsip Human-Computer Interaction.

Website dikembangkan dengan memperhatikan aspek **usability, visual hierarchy, consistency, navigation, dan user experience** agar pengguna dapat menemukan informasi dan berinteraksi dengan fitur website secara lebih mudah.

## Fitur

- Responsive website interface
- Navigation antar halaman
- Informasi mengenai JCI
- Interactive user interface
- Reusable UI components
- Responsive layout untuk berbagai ukuran layar
- Struktur halaman yang terorganisir

## Menjalankan Project
1. Clone repository
    git clone [repository-url]
    cd jci-website
2. Install dependencies
    pnpm install
    
    atau:
    
    npm install
3. Jalankan development server
    pnpm dev
    
    atau:
    
    npm run dev
    
    Kemudian buka:
    
    http://localhost:3000
